DARSim Organization

Here, you can explore the structure of the files and folders within this repository. The root folder is the src folder. Within this folder, you will find the following files and subdirectories. You can click on these files to inspect them.


The primary routines in this folder are darsim.m and startup_darsim.m. The first file, darsim.m, is the main function used to initiate the simulation process, starting from reading the input files to running the simulation and producing the results. The second file, startup_darsim.m, contains a series of routines that assist in the initialization of the code.
