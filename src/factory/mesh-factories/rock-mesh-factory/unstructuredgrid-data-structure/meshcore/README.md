# MeshCore
The MeshCore is a powerful mesh manager class powered by MRST 2023,
designed to handle general unstructured grids in 2D and 3D. 
It introduces numerous features that greatly enhance the accessibility 
and handling of meshes, making the process fast and straightforward.

With MeshCore, you can take advantage of the advanced grid generation 
capabilities offered by MRST, ensuring full compatibility with its grid 
generation functions. Additionally, we have implemented a routine that 
enables seamless compatibility between MRST and GMesh grids.
