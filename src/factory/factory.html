factory tree

The factory folder contains routines, functions, and classes used to instantiate objects of the simulation_factory class. Once initialized, the simulation factory object is responsible for creating simulation objects based on input file parameters.


discretization-factory contains routines for constructing the flux approximation discretization component within the simulation object. These routines depend on the data structure that describes the mesh. The DARSim release includes a new module for unstructured grids, while the original Cartesian and CPG discretization versions reside in the darsim_legacy folder.


fluid-property-factory contains routines for building the fluid model component of the simulation object.


mesh-factories contains functions, classes, and routines for constructing the fracture network. Within this folder, the fracture-factory includes routines for building fracture geometry, fracture mesh, rock mesh, fracture mesh intersections, and specific routines for EDFM and pEDFM. The main control for these processes is handled by the FractureFactory class.


rock-mesh-factory contains routines that build the data structure describing the rock matrix mesh. This data structure is added to the simulation object by the simulation_factory.


reservoir-property-factory contains routines for building components that describe the physical properties of the reservoir.


visualization-factory contains routines for creating visualizations of the simulation results. It incorporates legacy code from darsim-legacy.


well-property-factory contains routines for constructing the wells within the simulation. It also utilizes legacy code located in darsim-legacy.
