darsim_legacy

The darsim_legacy folder encompasses all the routines that were primarily developed for the older releases of DARSim. These routines include components such as the fluid model, formulation, grid description, coupling, non-linear solver, and more.


We highlight the writer folder, which contains the routines to produce VTK files with the solution. Some modifications to these routines have been made to allow exporting the VTK files to unstructured grids.


Several routines within the darsim_legacy folder have been altered compared to the last release, but efforts have been made to keep them as close to the original versions as possible. The plan is to eventually migrate and refactor these codes, integrating them with the DARSim routines of the new release.
