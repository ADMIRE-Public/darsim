Reader Tree

The reader folder contains all routines related to reading the input files and converting them into the simulation settings used to initialize the simulation_factory. This, in turn, generates a simulation object as described by the input files. The routines are based on a dynamic-input-reader that can automatically read new fields in the input files.


TXTreaderplus.m is the class that reads raw input files, locating the labels and associated keys.
reader_darsim3.m is the main reading class that converts TXTreaderplus objects into new DARSim settings. It adds default settings if a given label is missing.
blueprint_factory.m organizes the information into related blueprints of the same type.
darsim2_settings_factory.m is a compatibility layer that translates blueprints into a settings file format consistent with former DARSim releases.


The default-configuration-settings folder contains the default configuration settings to be added if labels are not found in the input files. The subdirectory blueprint_settings contains the fields that comprise and organize the blueprints.
